# Transformador Java

Exemplo de interface funcional em Java usando Lambda Expressions para transformar texto em maiúsculas.

## Exemplo

```
Transformador toUpperCase = s -> s.toUpperCase();
System.out.println(toUpperCase.transformar("java"));
```

**Saída:** `JAVA`

## Tecnologias

- Java
- Interfaces Funcionais
- Lambda Expressions
